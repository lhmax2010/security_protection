Locally cross-compiled unmodified upstream FFmpeg 8.0.1. These libraries are not board extracts. Corresponding source: https://ffmpeg.org/releases/ffmpeg-8.0.1.tar.xz . Complete build script/configuration/log are in the parent directory; LGPL 2.1 license is included. `libavcodec-unstripped.so` retains .symtab; `libavcodec-stripped.so` derives from it via --strip-unneeded. Companion libavutil is included for linkage. Static analysis only; no target binary executed.
